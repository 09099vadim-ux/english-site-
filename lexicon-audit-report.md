# Повторная проверка раздела «Лексика»

Проверено по полному пользовательскому заданию на модернизацию раздела.

| Требование | Результат |
| --- | --- |
| Сохранение исходного содержания | Исходные 163 единицы и 24 группы сохранены; учебные данные при повторной проверке не изменялись |
| Новые группы | Добавлена 21 группа; всего 45 групп в 6 тематических категориях |
| Индивидуальные карточки | 248 уникальных единиц; у каждой четыре основные вкладки |
| Дополнительная вкладка выражений | Только Price, Cost, Value, Worth; 27 пунктов, 33 варианта |
| Общий и индивидуальный списки выражений | Используют один источник данных |
| Восемь учебных вкладок каждой группы | Проверены все 360 вкладок |
| Поиск и ссылки | Поиск по группам, открытие карточек, переходы между группами сохранены |
| Переводы | В проверенных представлениях карточек каждому английскому примеру соответствует русский перевод |
| Адаптивность и взаимодействие | Проверены узкие экраны, управление клавиатурой, модальные окна и отсутствие ошибок JavaScript |

## Найдено и исправлено

1. При перерисовке навигации терялся клавиатурный фокус. Теперь выбранная группа или вкладка получает фокус; вкладки выражений поддерживают стрелки, Home и End, один активный tabindex и связь с панелью.
2. В некоторых предложных моделях часть речи обозначалась слишком общо. Существительное и глагол теперь подписаны отдельно. У REQUEST разделены существительное A REQUEST FOR и глагольная конструкция REQUEST SOMETHING FROM SOMEONE.
3. Отдельные свободные обстоятельства времени и места могли выглядеть как управление слова. Такие строки исключены из индивидуальной справки; исходные данные и групповые уроки сохранены.
4. У BESIDES отдельно показаны связующее наречие и предлог; у THOUGH — союз и конечное наречие. Для каждого приведён пример с переводом.

## Проверка исправлений

- Chromium / Playwright: все 45 групп, 360 вкладок, 248 карточек с четырьмя вкладками, 27 пунктов выражений и 33 варианта.
- Отдельные проверки фокуса, стрелок, Home / End, поиска и точных подписей предложных моделей.
- Карточки на ширине 320, 375 и 1440 px; отсутствие горизонтального переполнения в проверенных представлениях.
- Синтаксис JavaScript и сохранение всего HTML вне скрипта лексики.

Это проверка структуры, взаимодействия и конкретных языковых исправлений, а не независимая словарная экспертиза каждого утверждения. Прямое открытие file:// не проверено из-за политики тестового браузера. Тренажёр использует исходный банк для 24 исходных групп: новые задания в пользовательский объём работ не входили.

Дополнительная регрессия пройдена: четыре формата тренажёра, сравнение слов, скрытие и восстановление столбцов, 45 групп на мобильном экране, 11 тем оформления и работа после отключения сети у уже загруженной страницы.
