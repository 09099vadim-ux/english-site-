# Polite English — этапы 2–3

## Реализовано

- Вкладка «Грамматика смягчения речи»: две группы по два независимых столбца, 53 конкретных конструкции. Основные способы и разновидности выбираются над примерами. До выбора примеры не показаны. Прямой и смягчённый варианты с переводами расположены в одной горизонтальной строке. Для каждого столбца есть отдельная кнопка новых примеров. Отдельного выбора времени или типа предложения нет.
- Все четыре столбца сохраняют выбор независимо. Постоянный учебный пример явно отделён от результата онлайн-генерации.
- «Рабочая и учебная переписка»: шесть карточек в сетке 3×2 на компьютере, ровно по два основных примера и одна справочная кнопка в каждой. Шесть самостоятельных справок: сначала связный текст нюансов, затем таблица строго из трёх столбцов. Всего 90 конструкций с примерами и русским переводом.
- Алгоритм: строго четыре параметра — 10 контекстов, 4 уровня, 3 типа предложения и 16 целей. Сочетания проверяются; для заведомо неудачных предлагается изменить тип без сброса остальных параметров. Автоматический запрос после завершения выбора с задержкой 350 мс; повторная генерация сохраняет параметры.
- Единый клиент онлайн-генератора: загрузка, тайм-аут, отмена, проверка формата, безопасное отображение, понятные ошибки и повторный запрос. При неудачной повторной генерации сохраняется предыдущий результат.
- Серверный адаптер для поставщика с OpenAI-совместимым Chat Completions API: закрытый env-ключ, allowlist origin, ограничения частоты/параллелизма/размера, проверка входа и ответа, максимум две попытки при неверном формате, no-store. Текст приложения не логирует.

## Фактический статус генерации

Реальный поставщик и сервер пока **не подключены**: в исходном проекте не было endpoint, ключа или выбранного провайдера. GitHub Pages не запускает серверный код. Генератор не выдаётся за работающую онлайн-модель. На опубликованной странице виден статус отсутствия подключения; учебные материалы, справки и настройки работают.

Для подключения требуется развернуть `server/polite/server.mjs`, выбрать модель, задать серверные `MODEL_API_KEY`, `MODEL_NAME`, `MODEL_BASE_URL`, `ALLOWED_ORIGINS`, затем указать публичный endpoint в `window.PoliteGeneratorConfig`. Подробности — `server/polite/README.md`. Платный сервис не выбран, аккаунты не создавались, секреты не публиковались. Бесплатность и безлимитность не обещаются.

## Отсутствие накопления

Сохраняются только четыре текущие пары и один текущий результат алгоритма в памяти страницы. Новая генерация заменяет объект и DOM, не добавляет историю. При смене параметров устаревший запрос отменяется; проверяется номер актуального запроса. В localStorage/sessionStorage/IndexedDB генератор не пишет. При перезагрузке результаты исчезают. Постоянные учебные примеры — авторский материал, а не сохранённые результаты модели.

## Проверки

- Регрессия этапа 1: все вкладки, 11 справок, WH-таблица, таблицы ошибок, клавиатура и закрытие модальных окон.
- Все 53 разновидности смягчения, независимость столбцов; 6 справок/90 строк переписки, ровно 12 лицевых примеров; 4 параметра алгоритма и ограничения.
- Экран 320/375/768/1440; нет горизонтального переполнения страницы; пары примеров остаются горизонтальными внутри столбца.
- На тестовом endpoint: автоматический запрос после завершения выбора, повторная генерация и замена без накопления, сохранение результата при ошибке, очистка после reload, отмена устаревшего результата, HTML ответа выводится как текст.
- Серверные тесты `node --test tests/polite-server.test.mjs`: origin, параметры, схема, отсутствие настройки, ограничение частоты, проверка конструкции и вопросительного типа, ограниченная повторная попытка.
- Синтаксис всех новых JS/MJS, `git diff --check`; ошибок JavaScript в браузерных проверках нет.

Онлайн-качество реальной модели не проверялось: provider не подключён. Схема/подстрока/пунктуация не гарантируют абсолютной грамматической точности; требуется подходящая модель и проверка после её выбора. Технические журналы хостинга и модели зависят от выбранных сервисов.
