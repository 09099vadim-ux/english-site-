# Подключение онлайн-генерации Polite English

Это отдельный сервер Node.js 20+, а не часть GitHub Pages. Конкретный поставщик модели пока не выбран. Рабочий сайт честно показывает отсутствие подключения и предлагает постоянные учебные примеры.

1. Разместите `server/polite/server.mjs` и `assets/polite/extra-data.js` с сохранением относительных путей на выбранном Node-хостинге. Запуск: `node server/polite/server.mjs`.
2. В секретах сервера задайте `MODEL_API_KEY`, `MODEL_NAME`, `MODEL_BASE_URL` (совместимый с OpenAI Chat Completions HTTPS URL, заканчивающийся, например, на `/v1`). Провайдер должен поддерживать `response_format: json_object`. Цена и лимиты зависят от выбранного поставщика.
3. `ALLOWED_ORIGINS=https://09099vadim-ux.github.io` — точный origin сайта. Несколько origin разделяются запятой. `PORT` — порт сервера, по умолчанию 8787. Внешний доступ должен использовать HTTPS через хостинг/reverse proxy.
4. Перед `assets/polite/generator.js` подключите конфигурацию: `window.PoliteGeneratorConfig={endpoint:'https://YOUR-SERVER/api/polite'};`. Это публичный URL, не секрет. Не добавляйте ключ в HTML, JS или репозиторий.

Сервер не хранит историю. Текущий предыдущий результат передаётся только для разнообразия; текст не логируется приложением. Поставщик и хостинг могут иметь собственные технические журналы — проверьте их правила.

Ограничения: 10 запросов в минуту на IP, 4 одновременно на процесс; максимум 12KB входа; 22 секунды на запрос; до двух попыток при неверном JSON. Вход, origin, схема ответа и вхождение конструкции проверяются. Тип вопроса проверяется по конечному знаку; это не полная грамматическая проверка. Качество английского и русского зависит от модели.

В многопроцессном или serverless-развёртывании добавьте общее ограничение частоты на шлюзе и лимит расходов у поставщика. CORS не является полной защитой от злоупотребления открытым endpoint. За reverse proxy настройте реальный IP на уровне шлюза: приложение намеренно не доверяет произвольному X-Forwarded-For.

Тестовый локальный режим `ALLOW_LOCAL_MODEL=1` разрешает HTTP только для разработки; не включайте его в production. Для неизвестного поставщика онлайн-работа не заявляется как проверенная. Контракт, обработка ошибок, отмена и отсутствие накопления проверяются с тестовым сервером.
