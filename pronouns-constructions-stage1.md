# Неопределённые местоимения: связанные конструкции — этап 1

Изменён существующий `8989.html`. По новому промпту выполнен только первый этап; остановка требуется после каждого этапа.

## Готово

- Внутри «Неопределённых» добавлены три способа навигации: «По основе», «По окончанию», «По конструкциям».
- Прежние фильтры SOME / ANY / EVERY / NO и -ONE / -BODY / -THING / -WHERE сохранены. Они показывают те же 16 карточек; выбор в двух режимах запоминается независимо.
- Созданы шесть полноценных переключаемых карточек: ELSE, ELSE’S, OF, OTHER, SINGLE, AT ALL.
- В каждой карточке крупное название, перевод и грамматическая характеристика, затем шесть блоков: значение и логика; формулы; грамматические особенности; примеры; взаимозаменяемость; ошибки.
- На широком экране три блока расположены слева и три справа, на узком — в одной колонке.
- Подготовлен общий набор **105 нормализованных сочетаний**. В него входят **все 84 сочетания обязательного первоначального списка** и 21 дополнительное, включая вопросительные формы с ELSE и другие OF-модели.
- Каждая запись содержит сочетание, перевод, пояснение, пример, перевод примера, тип конструкции, основу и связь с существующим словом, когда она грамматически уместна.
- Примеры внутри подробной карточки фильтруются по SOME / ANY / EVERY / NO и дополнительным случаям. Длинный список прокручивается внутри своего блока.
- Добавлены 23 формулы с переведёнными примерами, 15 сравнений и 13 разборов ошибок. Для каждого сравнения и разбора есть цельный итог из 2–3 предложений.
- Пары расположены горизонтально: неправильный вариант слева, правильный справа; допустимые варианты отмечены двумя галочками. Под каждым примером стоит русский перевод.

## Грамматические акценты

- ELSE после неопределённых и вопросительных форм; различия с OTHER и ANOTHER.
- ’S после всей группы SOMEONE ELSE; WHO ELSE’S и отличие от WHO’S.
- OF после количественной формы, а не произвольно после SOMEONE или EVERYWHERE. EVERYONE и EVERY ONE OF разделены.
- Единственное число EACH OF / ONE OF / EVERY ONE OF; согласование ALL OF и NONE OF с учётом набора или неисчисляемого значения.
- OTHER / OTHERS / ANOTHER / THE OTHER / THE OTHERS; два контекстных значения EVERY OTHER.
- Усилительное EVERY SINGLE / NOT A SINGLE и обычное SINGLE ROOM.
- AT ALL в отрицаниях, вопросах, условиях и подходящих утвердительных контекстах; запрет «только с отрицанием» не вводится.

- Все три режима навигации и шесть карточек, по шесть блоков в каждой.
- Все 105 записей, фильтры примеров, соответствие английских и русских блоков, формулы и итоги.
- Наличие всех 84 обязательных сочетаний проверено по списку из пользовательского файла.
- Порядок неправильного/правильного вариантов, двухколоночные пары и 2–3 предложения в итогах.
- Клавиатура, сохранение фильтров, отсутствие дубликатов 16 прежних карточек.
- Экраны 320 / 375 / 768 / 1600 px; отсутствие горизонтального переполнения страницы.
- Существующие личные и относительные местоимения и работа загруженной страницы после отключения сети.
- Ошибок JavaScript не обнаружено; синтаксис модуля и git diff --check пройдены.

При исключении трёх новых изолированных блоков (`pr4-style`, `pr4-data`, `pr4-script`) HTML побайтно совпадает с предыдущей версией. Прежние 160 моделей, карточки, SVG, остальные разделы и их код не удалялись. Внешних библиотек и новых сетевых зависимостей нет.
