# Упражнения тематического словаря — этап 1

Раздел добавлен в 8989.html после «Английских слов». В главном меню используется уточнение «Упражнения словаря», чтобы отличать его от уже существующей вкладки общих упражнений; заголовок внутри — «Упражнения».

Открыть: https://09099vadim-ux.github.io/english-site-/8989.html#vocabulary-exercises

## Что работает на первом этапе

- Шесть самостоятельных вкладок типов упражнений.
- Общий источник: «Все 25 тем» либо одна из 25 действительных тем. Еда и напитки выбираются из соответствующих внутренних списков общей темы.
- Временные независимые наборы: по 10 вопросов у типов 1/2/3/6, по 5 раундов из четырёх слов у типов 4/5.
- Генерация подходящих слов при первом открытии типа, без повторов английского целевого слова в наборе. Предложения с пропуском отбираются только при точном наличии соответствующего слова в общем примере.
- Номер вопроса, черновики полей и раскрытие материала сохраняются при переключениях типов и основных разделов.
- Новые вопросы заменяют только текущий набор. Другие пять сохраняются. Предыдущие наборы не архивируются и не записываются в хранилище.
- Смена источника требует подтверждения. Отмена и Escape сохраняют наборы. После подтверждения несовместимые наборы удаляются, новые создаются при открытии соответствующей вкладки.
- У числительных и суффиксов нет изображений; в типе 5 выводится честное пояснение о необходимости другой темы, а не фиктивные иллюстрации.
- Клавиатурное управление вкладками и адаптивные поля.

Это этап архитектуры и интерфейса: на странице явно обозначено, что поля пока сохраняют **черновики** и не проверяют ответы. Законченные способы ответа, подсказки, проверка и двуязычная обратная связь относятся к этапам 2 и 3.

## Единый источник

Словарь переведён с data.json на один авторитетный data.js без изменения слов, примеров и изображений. Отдельной копии данных для упражнений нет. shared.js лениво загружает этот файл один раз для обоих разделов, строит индекс устойчивых ID и предоставляет общие объекты слов.

Обычные слова и числительные используются непосредственно. Адаптеры суффиксов ссылаются через свойства-геттеры на исходные строки таблиц; отдельная база производных не сохраняется. У временного вопроса есть только ID слов, черновики и состояние интерфейса. Картинки используются по прежним путям; новых изображений этот этап не создаёт.

Загрузка data.js через обычный script, без fetch JSON, позволяет использовать общий источник в локальной копии. Зависимостей от нейросети или серверного API нет.

## Проверки

- Проверка синтаксиса всех новых JS.
- Playwright: шесть наборов, количество элементов, уникальные ID, сохранение номера/черновика/раскрытия, отсутствие автоматического засчитывания, изолированное обновление, смена темы с подтверждением и отменой, исключения для изображений, клавиатура, ширины 320/375/768/1440.
- Подтверждён один запрос общей базы при переходе из упражнений в словарь и использование того же объекта слова обоими представлениями.
- После миграции источника повторно прошла проверка 25 тем словаря, 13 суффиксов, числительных, поиска, навигации и шести ширин.
- Офлайн: сеть отключена, HTML/JS/CSS/данные/картинки подавались браузеру непосредственно из локальных файлов тестовым перехватчиком; словарь и сохранение черновиков работают. Прямую навигацию file:// блокирует административная политика браузера стенда, поэтому этот конкретный способ открытия здесь не подтверждён.
- В браузерной проверке нет ошибок JavaScript. Единичный ответ GitHub Pages 503 при ранней публичной проверке изображения повторно проверен отдельно: HTTP 200, корректный WebP.

## Остановка после этапа

Новый пользовательский промпт прямо требует: «Не переходи к следующему этапу без моего подтверждения». Поэтому выполнен только этап 1 упражнений. Этапы 2 и 3 не объявляются готовыми и не запускаются автоматически. Предыдущий тематический словарь завершён полностью.
