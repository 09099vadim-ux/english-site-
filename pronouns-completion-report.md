# «Местоимения»: завершение этапов 2–3

Последующая организация и дополнительные сочетания описаны в [pronouns-structure-audit.md](pronouns-structure-audit.md): теперь три верхние вкладки, а этапы 2–3 находятся в «Полезно знать».

Файл сайта: `8989.html`. Оставшиеся этапы выполнены по последующей команде пользователя «давай все этап». Первый этап и другие разделы сохранены.

## Этап 2

### Each / Every

- Две обзорные карточки с переводами, грамматической ролью и примерами.
- Общий принцип индивидуального рассмотрения и полного охвата без ложного абсолютного противопоставления.
- Раскрываемая таблица: шесть строк, четыре столбца; положение EACH, размер группы, OF, интервалы, цена за единицу, согласование.
- Десять связанных форм в сетке 5 × 2 на широком экране; адаптация до двух и одной колонки.

### One / Ones

- Две основные карточки и объяснение отличия типа предмета от ссылки на конкретный предмет через IT / THEM. Отдельно оговорено, что THE ONE тоже может обозначать определённый предмет.
- Пять внутренних вкладок: основные отличия; важнейшие сравнения; связанные конструкции; дополнительные тонкости; когда можно / когда нельзя.
- Таблица из шести строк и четырёх столбцов.
- Четыре наглядных сравнения с переводами и краткими итогами.
- Десять связанных форм и восемь раскрываемых пояснений: пропуск, числительное ONE, обобщённое ONE, ONE’S, ONESELF, ONCE, исчисляемость, SOME / ANY.
- 12 случаев «Когда можно» — три блока по четыре карточки; 8 случаев ограничений — два блока по четыре карточки. В каждом блоке сетка 2 × 2.
- У каждой из 20 карточек круглая кнопка справки, пояснение и пять дополнительных ситуаций с переводами. В ограничениях неподходящий и подходящий варианты идут вертикально, каждый со своим переводом.
- Грамматические ошибки, изменение смысла, недостаточный контекст и стилистическая избыточность подписаны отдельно. Допустимые избыточные формы не объявлены безусловными ошибками.
- Справки закрываются крестиком, Escape и нажатием снаружи; восстанавливаются прокрутка и фокус.

## Этап 3

- 11 карточек в трёх колонках: WHO, WHOM, WHOSE, WHICH, THAT, WHAT, WHOEVER, WHOMEVER, WHATEVER, WHICHEVER, WHATSOEVER.
- Дополнительных вкладок внутри этого подраздела нет. WHERE / WHEN / WHY в набор не добавлялись.
- На лицевой стороне каждой карточки ровно три интерактивных заголовка: функция, возможность пропуска, взаимозаменяемость.
- Все 33 пояснения заменяют лицевую сторону внутри той же карточки. Кнопка X возвращает исходный вид; заголовок пояснения центрирован, основной текст читается обычным способом.
- Для правильного и неправильного вариантов используются соседние колонки: слева неподходящий, справа правильный. Если оба варианта допустимы, это явно подписано.
- У каждого сравнения свой итог — один абзац из двух-трёх коротких предложений.
- Разобраны подлежащее и дополнение; ограничительные и дополнительные придаточные; вынесенные предлоги; притяжательное WHOSE для людей и предметов; свободное WHAT; внутренняя роль WHOEVER / WHOMEVER; выбор WHATEVER / WHICHEVER; усилительное WHATSOEVER.
- Относительное WHICH в ограничительном придаточном не объявлено неправильным только из-за американского редакторского предпочтения THAT. Разговорное объектное WHOEVER отделено от формального WHOMEVER. WHATSOEVER не представлено обычным относительным местоимением.

## Проверки

Chromium / Playwright:

- Каждая новая основная вкладка, обе раскрываемые области Each / Every, пять вкладок One / Ones и два переключателя случаев.
- Все 20 справок и все 100 дополнительных ситуаций; соответствие английских и русских блоков.
- Все 11 лицевых карточек относительных конструкций и все 33 внутренних справки, возврат X, отсутствие модального окна в этом подразделе.
- Сетка 5 × 2, сетки 2 × 2 и трёхколоночный набор относительных карточек на широком экране.
- Соседние колонки сравнений относительных конструкций и вертикальные пары ограничений One / Ones.
- Крестик, Escape, закрытие снаружи, возврат фокуса и восстановление прокрутки в справках случаев.
- Переключение вкладок клавиатурой, четыре ширины: 320 / 375 / 768 / 1600 px; отсутствие горизонтального переполнения страницы.
- Пять тем оформления, прямые ссылки на новые подразделы, работа после отключения сети у загруженной страницы.
- Регрессия первого этапа: семь личных вкладок с пятью формами, 16 неопределённых карточек, восемь фильтров без дубликатов. Проверен переход в старый раздел «Артикли» и обратно.
- Ошибок JavaScript не обнаружено. Синтаксис модуля и `git diff --check` пройдены.

В сохранённом HTML присутствует панель расширения браузера, которая перекрывала новые кнопки. Она скрыта только при активном разделе «Местоимения», аналогично существующим исключениям других разделов.

Проверка сохранности: при удалении трёх новых блоков (`pr2-style`, `pr2-data`, `pr2-script`) HTML побайтно совпадает с исходной версией перед этапами 2–3. Новых библиотек и сетевых зависимостей для учебных данных нет.
