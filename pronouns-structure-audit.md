# «Местоимения»: повторная сверка и новые правки

Файл: `8989.html`. Сверены исходный полный промпт «Местоимения» и последующие уточнения пользователя. Новая организация заменяет прежнюю навигацию, а не добавляет второй раздел.

## Что было и что изменено

| Область | До уточнения | Теперь |
| --- | --- | --- |
| Верхняя навигация | Шесть вкладок; часть стояла слева | Ровно три центрированные вкладки: «Личные», «Неопределённые», «Полезно знать» |
| Each / Every, One / Ones, относительные формы | Самостоятельные верхние вкладки | Три горизонтальных подраздела внутри «Полезно знать» |
| Once | Пояснение в дополнительных тонкостях One / Ones | Сохранено и открывается отдельной горизонтальной кнопкой ONCE в этих тонкостях; ONCE не объявлено формой ONES |
| Связанные конструкции | Отдельная верхняя вкладка из восьми общих карточек | Распределены внутри 16 подходящих неопределённых форм; восемь исходных примеров сохранены |
| Дополнительные тонкости One / Ones | Вертикальный список раскрываемых пунктов | Восемь горизонтальных кнопок над сменяемым содержимым |
| Значения и сравнения неопределённых форм | Аккордеоны, при раскрытии карточка занимала всю строку | Лицевая сторона заменяется внутренним экраном в той же карточке; X возвращает её. Ширина, место в сетке и сам экземпляр карточки сохраняются |
| Сравнения в карточке | Три раскрываемые группы | Четыре горизонтальных переключателя: по основе, окончанию, конструкции и смыслу |
| Ширина | Контрольная ширина раздела 1000 px | 1180 px на широком экране (+18%); ширина карточек увеличилась вместе с сеткой. На телефоне ширина ограничена окном |

## Распределение сочетаний

Добавлены **160 моделей для 16 слов**. Их можно найти через те же четыре основы SOME / ANY / EVERY / NO и четыре окончания -ONE / -BODY / -THING / -WHERE. Фильтры выбирают существующие карточки, не создавая копии.

В карточке: «Значение и примеры» → «Сочетания». Модели выбираются горизонтальными кнопками; под ними — пояснение, английский пример и русский перевод.

Показаны применимые варианты:

- ELSE после формы; ELSE’S для притяжательных примеров с людьми.
- Прилагательные и уточнения после неопределённых форм.
- Инфинитивные модели, уточняющие части с WHO / THAT и уточнения о месте.
- EVER в вопросах, условиях и других подходящих контекстах. EVER не смешивается с основой EVERY.
- THEMSELVES / BY THEMSELVES для людей и ITSELF для вещей; искусственные составные слова с SELF не образуются.
- OTHER THAN, EXCEPT, BUT, AT ALL там, где соответствующая модель естественна.
- SOME OF / ANY OF / EVERY ONE OF / NONE OF как родственные количественные конструкции. Это не приписывание OF словам SOMEONE, SOMETHING или SOMEWHERE.
- EVERY SINGLE и отрицательные конструкции с A SINGLE перед существительным.
- SOME, BUT NOT ALL и применимые модели ALL.
- Для мест — ELSE, FROM, NEAR, инфинитивные и уточняющие конструкции, исключения. NOWHERE NEAR и FROM NOWHERE объясняются с учётом их собственного смысла.

Это набор частых учебных моделей, а не утверждение о перечислении всех теоретически возможных английских сочетаний. Слова не подгоняются под одинаковый шаблон ради количества.

## Сверка остальных требований исходного промпта

- Личные местоимения: две обзорные таблицы, семь вкладок, пять форм, SVG и особенности ITS / IT’S, YOURSELF / YOURSELVES и singular THEY сохранены. Заголовки таблиц остаются на русском.
- Неопределённые формы: все 16 карточек, цвета и различные рисунки людей, вещей и мест сохранены. Формы на -WHERE не объявлены личными местоимениями. Значения, примеры и сравнения доступны внутри карточек.
- Each / Every: две главные карточки, сравнительная таблица и десять связанных форм сохранены.
- One / Ones: пять учебных вкладок, таблица, четыре сравнения, десять связанных форм, восемь тонкостей, двенадцать допустимых случаев и восемь ограничений сохранены.
- Все 20 справок случаев содержат по пять дополнительных ситуаций с переводами. Сохранены X, Escape, закрытие снаружи, фокус и прокрутка.
- Относительные конструкции: все 11 карточек, три интерактивных пункта каждой и 33 внутренних пояснения сохранены. Они не перенесены в модальные окна. Сетки правильных/неподходящих вариантов и краткие итоги сохранены.
- Другие разделы сайта не переписаны; новых сетевых зависимостей нет.

## Источники и проверка языка

Для общих правил неопределённых форм, согласования, ELSE / ELSE’S и положения уточнений использована [British Council: Indefinite pronouns](https://learnenglish.britishcouncil.org/grammar/english-grammar-reference/indefinite-pronouns). Страница была доступна при проверке. Учебные примеры для конкретных моделей составлены отдельно; источник не заявляется подтверждением каждого из 160 авторских предложений. Cambridge при обращении вернул HTTP 403 и не использовался как прочитанный источник.

## Проверки

- Три верхние вкладки и три подраздела полезных знаний; центрирование и контрольная ширина 1180 px.
- Все 16 карточек: 32 внутренних экрана, 64 сравнительных представления, 160 моделей с переводами.
- При открытии внутренних экранов проверены неизменность ширины, горизонтальной позиции и индекса карточки в сетке.
- Фильтры по основе и окончанию, отсутствие дубликатов, возврат X и фокуса, клавиатурное переключение.
- Восемь горизонтальных кнопок тонкостей вместо аккордеонов.
- Регрессия этапов 2–3: все 20 справок случаев, 100 дополнительных ситуаций и 33 относительных пояснения.
- Экраны 320 / 375 / 768 / 1600 px, старые прямые ссылки, переходы между разделами и работа после отключения сети у загруженной страницы.
- Ошибок JavaScript не обнаружено; синтаксис модулей и git diff --check проверены.

Исходные учебные JSON `prn-data` и `pr2-data` не изменялись. При исключении новых изолированных блоков и двух доработанных контроллеров весь остальной HTML совпадает с предыдущей версией.
