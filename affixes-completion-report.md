# Суффиксы и приставки

Новый блок встроен в существующий раздел «Словообразование» файла «Продвинутая грамматика — упражнения.html». Из «Лексики» добавлен прямой переход к нему. Ссылка: `#affixes`.

Приставки: 60 элементов из приложенного prefixes.html в шести смысловых группах. Каждая группа имеет описание, VN1 с четырьмя столбцами (приставка, основной смысл, когда используется, пара слов с двумя переводами) и VN2 с тремя карточками в ряд на компьютере. Примеры уточнены: вместо исторически связанных или неочевидных основ выбраны прозрачные пары, где это возможно. In-/im-/il-/ir-, en-/em- отмечены как варианты, научные элементы не выдаются за свободно присоединяемые приставки. Для AmE учтено написание vice president, coauthor и др.

Суффиксы: четыре группы по части речи, 49 карточек моделей. Таблицы содержат все 181 прежних примеров и отдельные столбцы английского текста и русского перевода. Описания и таблицы выровнены по центру. Уточнены несколько явно несогласованных примеров в новом представлении (atomic для -ic, accessible для -ible). Орфографические модели -ily/-ably/-bly и отсутствие -ly объясняются как модели, а не отдельные универсальные суффиксы. Сохранившиеся исходные материалы доступны в раскрываемом блоке вместе с прежними тренажёрами.

Сравнение открывается внутри границ своей карточки, заменяя лицевой текст. Крестик слева сверху и Escape возвращают лицевую часть; фокус возвращается к кнопке. У каждого сравниваемого элемента — схема, слово, перевод и смысловой оттенок после перевода. Горизонтальная прокрутка сравнения ограничена карточкой. Близкие элементы из соседних групп привлекаются там, где это содержательно необходимо: pro-/anti-, vice-/ex-.

Проверено: 109 карточек; 241 строка таблиц; 115 доступных переключений сравнений из карточек; схемы, переводы, внутренние окна и закрытие; клавиатура; экран 375/768/1440. Ошибок JavaScript нет. Исходный файл prefixes.html использован как учебный материал, отдельный сайт не создавался.

Файлы: основной HTML, `assets/affixes/data.js`, `app.js`, `style.css`, этот отчёт.
