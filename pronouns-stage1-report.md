# «Местоимения»: этап 1

Обновление: этапы 2–3 впоследствии завершены по команде пользователя. Итоговый статус — в [pronouns-completion-report.md](pronouns-completion-report.md). Ниже сохранён отчёт первого этапа.

Раздел добавлен в существующий файл `8989.html` отдельной кнопкой основного меню. Прямая ссылка: `8989.html#pronouns`.

## Готово

- Две обзорные таблицы личных форм: I / You / We / They и He / She / It.
- Семь индивидуальных вкладок, по пять блоков в каждой: подлежащее, дополнение, притяжательное определение, самостоятельная притяжательная форма, возвратная форма. Первые четыре блока — в основной сетке, возвратный — снизу по центру.
- Уточнения ITS / IT’S / ITSELF, отсутствие обычной самостоятельной притяжательной формы IT, YOURSELF / YOURSELVES, singular THEY.
- Семь типов компактных встроенных SVG: говорящий, собеседник, круг и треугольник для HE / SHE, куб для IT, группы WE / THEY.
- 16 уникальных карточек SOME / ANY / EVERY / NO. Навигация по четырём основам и четырём окончаниям фильтрует те же экземпляры карточек.
- Цвета и смысловые рисунки соответствуют группе и окончанию: люди, вещи, места; часть, возможный выбор, вся группа, отсутствие.
- У каждой неопределённой формы — пример с переводом, раскрываемые значения и сравнения по основе, конструкции и смыслу. Всего 48 сравнительных блоков с краткими итогами.
- Отдельная вкладка связанных конструкций: else, else’s, of, other, single, at all, прилагательное после неопределённой формы, инфинитивное уточнение.
- Формы на -WHERE прямо обозначены как наречия места. ANY не сводится к значению «любой»; у -ONE / -BODY не выдумываются постоянные смысловые различия.

## Проверено

Chromium / Playwright: две таблицы, семь личных вкладок и пять блоков каждой, 16 карточек без дубликатов, восемь фильтров, 48 сравнений, раскрытие справок, соответствие английских примеров русским переводам, управление вкладками стрелками / Home / End, фокус, экраны 320 / 375 / 768 / 1440 px, переходы между старым и новым разделами, взаимодействие после отключения сети у загруженной страницы. Ошибок JavaScript не обнаружено. Широкие обзорные таблицы на узком экране прокручиваются внутри своего контейнера, страница не переполняется.

Новые данные, SVG, стили и логика встроены в HTML и не требуют внешних библиотек или сети. Старые разделы и их исходный код сохранены.
