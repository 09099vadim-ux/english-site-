# Модальные глаголы и конструкции — этап 1

Раздел встроен в существующую вкладку «Модальные» файла «Времена и конструкции — упражнения.html».

## Реализовано

- Компактное введение и четыре справки: V1 без TO, TO + V1, V-ing и сложные формы.
- Восемь тематических групп, 40 уникальных выражений и 49 вхождений в группы. Выражение, относящееся к нескольким темам, использует одну исходную карточку.
- Сетка: четыре карточки на компьютере, две на планшете, одна на телефоне.
- Два уровня цвета: тема и централизованный индивидуальный оттенок выражения.
- Общая таблица ровно из пяти столбцов; 40 строк без дублей. Для 68 значений приведены отдельные примеры и русские переводы. Замены снабжены контекстом и пояснением различий; примеры раскрываются внутри ячейки.
- Единое модальное окно для справок и предварительных индивидуальных карточек. В карточке есть значения с примерами, модель, грамматические особенности и близкое выражение в конкретном смысле.
- Закрытие крестиком, Escape и нажатием снаружи; фон заблокирован, доступны внутренняя прокрутка, управление с клавиатуры, восстановление фокуса и положения страницы.
- Уточнено различие USED TO / BE USED TO / GET USED TO. Обычные конструкции не объявлены собственно модальными глаголами.
- Частотность качественная, без выдуманных числовых рейтингов.

Прежние материалы, сравнения и упражнения сохранены в раскрываемом блоке. В старом введении исправлено смешение модальных глаголов с HAVE TO / NEED TO; числовая «шкала вероятности» заменена качественными формулировками, уточнено отсутствие гарантированного результата у TRIED TO.

## Проверки

Chromium / Playwright: все восемь тематических вкладок, 49 карточек в группах, 40 ссылок общей таблицы, четыре справки, клавиатура, все способы закрытия, раскрытие примеров, 11 тем и ширина 320 / 375 / 900 / 1440 px. Ошибок JavaScript нет. Проверены снимки экрана для компьютера, телефона и справочной таблицы.

Проверка данных: уникальные ID; все ссылки групп и справок существуют; у каждого примера и каждой альтернативы есть русский перевод; не более пяти значений и трёх альтернатив на единицу.

Проверка сохранности: остальные разделы побайтно совпадают с предыдущей версией, все прежние ID сохранены.
