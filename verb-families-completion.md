# Семейства глаголов — этапы 2 и 3

Рабочий файл: `8989.html`. Самостоятельный раздел `#verb-families`.
Этап 1 сохранён ранее; `verb-families-stage1.md` описывает его историческое состояние.

## Выполненный объём

- 80 исходных базовых глаголов, без замен и повторов.
- 485 выбранных форм и конструкций: 117 приставочных/связанных форм, 210 фразовых, предложных и пространственных конструкций, 158 словообразовательных производных.
- 619 отдельных значений с английскими примерами и русскими переводами.
- У каждого выбранного значения: смысловая логика и грамматическая модель.
- У каждого выбранного значения фразовой/предложной конструкции: основной и дополнительный примеры, переходность, порядок слов, типичная ошибка, стиль, отличие от базового глагола, сравнение с отдельным английским предложением и переводом, ограничения замены и краткий итог.
- 240 примеров грамматических функций: Gerund, Present participle и Past participle для 80 глаголов. Производные-существительные отделены от грамматических форм.
- Добавлены важные связанные формы, например undertake, forgive, forget, input/output, и повседневные конструкции get back, put away, make up for. Связанные и лексикализованные формы не объясняются искусственным пословным переводом приставки.
- Добавлены реальные наречия usefully, playfully, thoughtfully, tellingly, movingly; фильтр наречий активен. Цепочки образования thoughtful → thoughtfully, replace → replaceable и forget → forgetful объясняются отдельно.

Это объём словарной подборки данной версии: счётчики относятся к выбранным формам и значениям, а не к неограниченному числу возможных сочетаний английских слов.

## Уровни и история

- Фразовые конструкции: каталог без предложений → значения с примерами → подробный разбор одного значения.
- Приставочные формы: каталог → все выбранные значения с подробными объяснениями.
- Производные: горизонтальный каталог с частями речи → подробные значения.
- Каждая область каждой семьи имеет собственный стек истории: идентификатор записи, индекс значения и позиция прокрутки. История других областей не перезаписывается.
- Стрелки назад/вперёд и кнопка «Список» работают внутри соответствующей области.
- Закрытие и повторное открытие восстанавливает текущие экраны. Повторный поиск той же конструкции сохраняет последнее открытое значение, а не сбрасывает его к первому.
- Состояние сохраняется в текущей сессии страницы; сохранение истории после перезагрузки не заявляется.

## Поиск и темы

- Поиск по базовым словам, производным, русским значениям и основным грамматическим формам.
- Одна исходная запись семьи; поиск и фильтры не создают дубликатов данных.
- Результат поиска производной открывает нужную категорию и форму.
- Темы назначены конкретным значениям, без наследования темы всем семейством. Тематическая ссылка может открыть непосредственно выбранное значение.
- При поиске базового `take` не открывается случайный `retake`.
- На узком экране найденный раздел прокручивается в видимую область; крестик закрытия остаётся доступен в закреплённом заголовке.

## Грамматические различия

В частности, разделены:

- take off: снять одежду / взлететь / быстро стать успешным / взять выходной;
- work out: тренироваться / решить / удачно сложиться;
- run over: наехать / быстро просмотреть / превысить отведённое время;
- make out: различить / целоваться / выписать документ / справиться;
- write up: подготовить текст / оформить дисциплинарное взыскание в AmE;
- put down: положить / унизить / усыпить животное;
- глагол с отделяемой частицей, неотделяемая конструкция и модель talk someone into doing something.

Уточнены модели keep on + -ing, set out to + V1, get through to, cut down on, keep up with и другие. Добавлены важные неправильные формы приставочных глаголов: redid/redone, retook/retaken, withdrew/withdrawn, foresaw/foreseen и т. д. Различия AmE/BrE и специальные употребления отмечены там, где они влияют на выбор: cooker, tell off, fit out, turning, fix on и др.

## Проверка

- Полный проход по исходным 80 семьям, 462 формам и 573 значениям.
- Отдельный проход по 17 дополнительным значениям и 23 новым производным с 29 значениями. Совокупно проверены 485 форм и 619 экранов значений текущей версии.
- Проверены основной и дополнительный английские примеры, наличие переводов и сравнений, переходы по всем трём категориям.
- Программный поиск по всем 485 формам: нужная семья найдена, дубликаты карточек отсутствуют.
- Проверены алфавит, смысловые темы, существительные/прилагательные/наречия, отдельная история областей, назад/вперёд, возврат к каталогу и восстановление последнего значения.
- Проверены ширины 320, 375, 768, 1024 и 1440 px: горизонтального переполнения нового раздела и окна нет.
- Проверены 11 тем, центрирование окна, Escape, Tab/Shift+Tab, возврат фокуса, работа без сети после загрузки, навигация в прежние разделы.
- Проверено отсутствие пустых обязательных полей: перевод, пример EN/RU, логика, модель; у фразовых значений — дополнительный пример, сравнение, порядок слов, ошибка, стиль и итог.
- Новые подробные экраны создаются по запросу в одном переиспользуемом окне; история хранит компактные ссылки, а не копии HTML.
- JavaScript проходит синтаксическую проверку. В перечисленных браузерных сценариях ошибок JavaScript не обнаружено.
- За пределами vf-style, vf-data и vf-script содержимое исходного HTML сохранено. Другие HTML-файлы не изменены. Новых внешних библиотек и API нет.
