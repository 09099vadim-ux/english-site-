# Условные предложения: IF и инверсия

Изменён существующий раздел «Условные предложения» файла «Времена и конструкции — упражнения.html».

## Распределение форм

- Zero: IF / WHEN для повторяемых ситуаций. WHEN не назван инверсией, а SHOULD / WERE / HAD не представлены как обычная модель Zero.
- First: IF / SHOULD без IF. Отмечены формальность и более осторожное предположение; SHOULD не переводится автоматически как «должен».
- Second: IF / WERE для состояния / WERE TO для действия. Объясняется, почему нельзя механически переставить любой Past Simple или потерять TO.
- Third: IF / HAD без IF, с сохранением V3 и прошлого результата.
- Mixed: отдельные направления «постоянное / настоящее → прошлое» и «прошлое → настоящее», с IF / WERE и IF / HAD соответственно.

Всего 13 вариантов написания. В «Примерах и контекстах» и «Формах предложений» появились горизонтальные переключатели с собственной памятью выбора. При переключении показаны формула, пояснение и примеры с непосредственными русскими переводами. Полные предложения расположены по три в ряд на широком экране, адаптивно на телефоне.

В общую таблицу добавлен блок из шести преобразований: First SHOULD; Second WERE; Second WERE TO; Third HAD; Mixed HAD; Mixed WERE. Каждая строка имеет формулы, полные предложения с IF и без IF, переводы и смысловое пояснение. Ссылка открывает нужный тип, направление Mixed и форму без IF.

## Нюансы, ошибки и сравнения

46 пунктов снабжены раскрываемыми примерами. Рассмотрены порядок NOT после подлежащего, V1 после SHOULD, TO после WERE TO, вспомогательный HAD и V3, различие условной инверсии и вопроса, сохранение времени результата. Особые IF + WILL в значении готовности и IF + Present Perfect не выданы за механические замены на SHOULD + V1.

В Mixed постоянное качество связывается с прошлой ситуацией, а будущий сценарий WERE TO не подставляется автоматически вместо постоянного навыка. Длительные состояния и прошлые действия не смешаны без пояснения.

Сравнения содержат все относящиеся к типу формы и краткий итог. Сохранены сравнения разных Conditional. В конце доступны «Краткий итог» и «Разбор всех вариантов»; полный текст занимает ширину раздела и выровнен по ширине.

## Сохранность

Исходный `cns-data` не изменён. Прежние подробные материалы двух Mixed сохранены также в раскрываемом блоке. Примеры исходных контекстов Mixed доступны в вариантах IF. Алгоритм выбора и интерактивные справки по V1/V2/V3 и временам сохранены. Остальные разделы, включая 120 записей каталога идиом, не изменялись.

Изменено поведение `cns-script`; новые данные и стили изолированы в `cni-data` и `cni-style`. Новых библиотек и сетевых зависимостей нет.

## Проверка правил

Проверен официальный материал British Council: https://learnenglish.britishcouncil.org/grammar/c1-grammar/inversion-conditionals

Подтверждены формальность инверсии, осторожный оттенок SHOULD, WERE TO / WERE для BE, HAD + V3 и отрицательное NOT после подлежащего. Примеры в проекте подготовлены для текущего урока с русскими переводами; происхождение сайта-источника не делает эти грамматические модели исключительно британскими.
